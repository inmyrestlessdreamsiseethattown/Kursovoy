# Курсовой проект по программированию — вариант 33

## Тема

Мониторинг технологического параметра реактора: расход азота.

## 1. Постановка задачи

Разработать программу на языке C для преобразования показаний расхода азота в показатель `Q(X)`, оперативного контроля состояния процесса и статистического анализа заданного фрагмента выборки.

## 2. Исходные данные

| Параметр | Значение |
|---|---|
| Измеряемая величина | Расход азота `X` |
| Единица измерения | л/мин |
| Диапазон входных значений | 5–70 л/мин |
| Количество измерений | 50 |
| Базовое значение | `Q₀ = 50` |
| Допустимое отклонение | `ΔQ = 7` |
| Участок статистического анализа | `Q[16..27]` |

## 3. Блок-схема

Показание преобразуется по кусочно-заданной функции:

\[
Q(X)=
\begin{cases}
\frac{(X-20)^2}{6}+10, & X<20,\\
3(X-32.5)+50, & 20\le X\le45,\\
2\sqrt{X-45+1}+60, & X>45.
\end{cases}
\]

Для оперативного контроля вычисляется абсолютное отклонение:

\[
D=|Q(X)-Q_0|.
\]

Если `D > ΔQ`, программа выводит состояние `ТРЕВОГА`; в противном случае — `НОРМА`.

## 4. Алгоритм работы

1. Запросить 50 измерений расхода азота.
2. Проверить, что каждое значение является числом и находится в диапазоне 5–70 л/мин.
3. Рассчитать `Q(X)` по соответствующей ветви кусочной функции.
4. Сравнить `|Q(X) − 50|` с допустимым отклонением 7.
5. Вывести исходные измерения, преобразованные значения и состояние.
6. Найти минимум и максимум среди `Q[16]`–`Q[27]`, вывести их значения и индексы.

## 5. Контрольный расчёт

При `X = 32.5`:

\[
Q(32.5)=3(32.5-32.5)+50=50.
\]

Отклонение равно `|50 − 50| = 0`. Так как `0 ≤ 7`, состояние — `НОРМА`.

## 6. Проверка и ограничения

Программа проверяет корректность числового ввода и диапазон каждого измерения. Статистический участок трактуется как 12 элементов с индексами 16–27 включительно; индексы в таблице и сообщениях нумеруются с единицы.

## 7. Заключение

Разработанная программа реализует заданное преобразование показаний, простейшую сигнализацию по абсолютному отклонению и статистический анализ выбранного фрагмента данных.
